# 🛠 System Repair Tool (DISM + SFC)

Простой инструмент для автоматического восстановления Windows через DISM и SFC.

## 📌 Возможности

* Проверка состояния системы (`CheckHealth`)
* Глубокое сканирование (`ScanHealth`)
* Восстановление системы (`RestoreHealth`)
* Проверка целостности файлов (`SFC`)
* Автоматический запуск с правами администратора
* Удобный интерфейс в консоли

## 🚀 Как использовать

1. Скачайте файл `System Repair Tool.bat`
2. Запустите его (лучше от имени администратора)
3. Дождитесь завершения всех этапов

## ⚠️ Важно

* Процесс может занять длительное время
* Во время выполнения не закрывайте окно
* Для `RestoreHealth` требуется интернет
